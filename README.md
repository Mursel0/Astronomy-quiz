# Astronomy Quiz 🌌

A multiple choice quiz game about space and astronomy, built with Python.

## Features
- 4 astronomy questions
- Multiple choice (a/b/c/d)
- Score tracking
- Correct/Wrong feedback

## Questions Cover
- Black holes
- The Milky Way galaxy
- Event horizon
- Stars and their life cycles

## How to Run
1. Install Python
2. Run: python astronomy_quiz.py
3. Answer each question with a, b, c or d

- Lists
- Dictionaries
- For loops
- User input
- If/else conditions
