# Astronomy Quiz 🌌

A multiple choice quiz game about space and astronomy, built with Python.

## Features
- 6 astronomy questions
- Random question order every time
- Multiple choice (a/b/c/d)
- Score tracking
- Shows correct answer if wrong
- Success percentage at the end

## How to Run
1. Install Python
2. Run: python astronomy_quiz.py
3. Answer each question with a, b, c or d

- Lists
- Dictionaries
- For loops
- User input
- If/else conditions
- Random module
